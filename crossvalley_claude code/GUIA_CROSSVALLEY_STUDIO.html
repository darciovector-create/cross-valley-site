Projeto

Criacao e organizacao
01
Criar Novo Projeto
Cria a estrutura completa de pastas para uma nova musica. O app pergunta o numero e nome (ex: 32 AMAZING GRACE) e gera todas as subpastas automaticamente.
02
Organizar Projeto
Reorganiza um projeto existente — move arquivos para as pastas corretas e cria pastas que estejam faltando.
📝

Conteudo

Geracao de material com IA
03
Gerar Legendas SRT
Gera arquivo de legenda .SRT sincronizado com a musica, baseado na letra em 02_ROTEIRO/musica.txt. Pede a duracao total e quando a voz comeca.
04
Gerar SEO Premium 2.0
Gera com IA: titulo otimizado para YouTube, descricao completa com palavras-chave e lista de hashtags para Instagram e TikTok. Salva em 08_SEO/.
05
Gerar Thumbnails IA
Gera thumbnails virais usando GPT Image com base nos momentos emocionais da letra. Estilo visual do canal: setas vermelhas, persona Cross Valley. Salva em 07_THUMBNAILS/.
06
Pacote YouTube Completo
Gera tudo para o YouTube de uma vez: titulo, descricao, tags e capitulos. Ideal para copiar e colar direto no YouTube Studio.
07
Gerar Prompts Story DNA
Gera prompts de imagem para as cenas do video, baseado no DNA Visual do canal (estilo Cross Valley). Usado para gerar imagens com IA para o video principal.
🔍

Analise

Inteligencia de conteudo
08
Story Analyzer
Analisa a letra e identifica os momentos mais virais — versos com maior potencial emocional. Gera pontuacao CTR para cada momento.
09
Storyboard Viral
Cria um storyboard completo com as cenas sugeridas para o video, baseado nos momentos de maior impacto emocional da letra.
10
CTR Intelligence
Relatorio de CTR (Click-Through Rate) previsto para as thumbnails. Mostra qual imagem tem mais chance de ser clicada e por que.
✂️

Edicao

Preparacao para o CapCut
11
Montar Sequencia CapCut
Organiza e nomeia os clipes na sequencia certa para importar no CapCut. Copia de 03_MIDIAS_BRUTAS/ para 04_CAPCUT/ com numeracao sequencial.
🚀

Publicacao

Reel Machine + Plataformas
12
REEL MACHINE — Cria video 45s
O coracao do sistema. Cria automaticamente um Reel vertical de 45 segundos (1080x1920):
  • Combina clipes PERSONA + SEM_PERSONA
  • Legendas karaoke sincronizadas (fonte Anton, cor dourada)
  • Whisper AI para sincronizacao palavra por palavra
  • Tela de CTA final com link do canal
  • Salva em 05_EXPORTACOES/REELS/
13
YouTube Shorts
Publica o Reel no canal Cross Valley Country Gospel como YouTube Short. Usa autenticacao OAuth ja configurada.
14
Instagram Reels
Publica o Reel no Instagram @crossvalleycountry. Inclui legenda com SEO e hashtags automaticamente. Login por Session ID configurado.
15
TikTok
Publica o Reel no TikTok do canal. Inclui titulo e hashtags automaticamente. Login por Session ID configurado.
16
★ PUBLICAR TUDO
O botao principal do sistema. Executa tudo em sequencia automatica:
  • 1. Cria o Reel de 45s (Reel Machine)
  • 2. Publica no YouTube Shorts
  • 3. Publica no Instagram Reels
  • 4. Publica no TikTok
Se uma plataforma der erro, continua as outras e mostra relatorio no final.
⚙️

Sistema

Configuracoes e memoria visual
17
Configurar Chave OpenAI
Define ou atualiza a chave de API do ChatGPT. Necessaria para geracao de imagens, SEO e analises de conteudo.
18
Aprovar Thumbnail
Move uma thumbnail para a pasta de aprovados (DNA_MEMORY/APPROVED). O sistema aprende com as escolhas para gerar imagens melhores no futuro.
19
Rejeitar Thumbnail
Move uma thumbnail para a pasta de rejeitados (DNA_MEMORY/REJECTED). Tambem faz parte do aprendizado do sistema visual.
20
Atualizar Persona Master
Atualiza a imagem de referencia do persona Cross Valley (foto oficial do canal). Usada como base para todas as geracoes de imagem com IA.
21
Diagnostico DNA
Relatorio do estado atual do DNA Visual: imagens aprovadas, rejeitadas, masterpieces e status geral do sistema de memoria visual.
